# warranty-claim-recovery

**A resumable case workflow that turns a manufacturer's rejected warranty claim into a corrected,
evidence-backed resubmission before the claim window closes — and survives being killed mid-case.**

> **Contract first.** `DECISIONS.md` ADR-001 fixes three claims, thirteen kill conditions and their
> thresholds, four retrieval baselines, and the hold-out rule. It was committed **before any source
> file existed**, and `git log` is the evidence. Thresholds may be raised; none may be lowered.

The build is in progress. Every number this file will eventually quote comes from a committed script
that reproduces it, and nothing is written here before it has been measured.
