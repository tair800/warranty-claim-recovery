The number this project is built around

{{ count_tile( "False recoveries", metric(recovery_artifact, "holdout_false_recoveries"), "hold-out cases gated recoverable whose ground truth is NOT_RECOVERABLE. ADR-001 §5 G: threshold 0.", true) }} {{ count_tile( "False denials", metric(recovery_artifact, "holdout_false_denials"), "hold-out cases withheld whose ground truth authorised recovery. Published by the evaluation harness as holdout_false_denials.") }} {{ count_tile( "Amount mismatches", metric(recovery_artifact, "amount_mismatches"), "recoverable amounts differing from the generator's truth, at exact Decimal equality. ADR-001 §5 F: threshold 0.") }}

A false recovery is reported as a count and is never folded into an F1. A combined score lets one false recovery be paid for by some number of correct ones, and there is no number of correct recoveries that pays for taking money from a manufacturer on a basis that does not exist. The two error directions also cost different people different things — a false recovery is a claim filed against a manufacturer with nothing behind it; a false denial is money the distributor was owed and never asked for — and a single figure that averages them tells nobody which one happened.
